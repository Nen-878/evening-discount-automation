1. ДЛЯ ПРОВЕРЯЮЩЕГО / ПОЛЬЗОВАТЕЛЯ
   - Дважды кликните Start_App.vbs.
   - CMD не открывается: приложение запускается через pythonw/pyw.

       • «Открыть лист для печати»
       • «Открыть папку»

2. ГОТОВЫЕ АРТЕФАКТЫ БЕЗ ЗАПУСКА
   - output\result.xlsx       — итоговый отчет для директора и цеха

   - PROMPT_AUDIT.md          — журнал AI-решений, ошибок и исправлений

3. ГДЕ ЧТО ЛЕЖИТ
   - input\   — исходная выгрузка 1С
   - output\  — готовые результаты
   - src\     — бизнес-логика
   - tests\   — автоматические тесты
   - docs\    — ТЗ, регламент, анализ, архитектура и QA-чеклист

4. ТЕХНИЧЕСКАЯ ПРОВЕРКА
   pip install -r requirements.txt
   python -m pytest -q
