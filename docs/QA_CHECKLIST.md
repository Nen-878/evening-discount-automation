## Ручной UX-QA

Проверено:
- `Start_App.vbs` открывает GUI без CMD;
- окно стартует максимизированным;
- итоговый Excel открывается из GUI;
- печатный лист открывается из GUI;
- если Excel открыт, пользователь получает понятное сообщение вместо traceback;
- в денежных ячейках нет локально подменяемого символа ₽;
- на `01_Директор` и `04_Контроль_данных` нет мешающего закрепления областей;
- на длинных таблицах закреплена только шапка;
- рабочие листы используют понятные человеку статусы и действия;
- позиции `MARGIN_ALERT` явно требуют решения директора;
- 43 READY-позиции попадают в печатный лист;
- запрещенные/просроченные/MARGIN_ALERT/problem barcode не попадают в печать;
- имена файлов внутри Windows-safe архива — ASCII, чтобы избежать mojibake при распаковке.
